# Стенд устойчивости сторонних разборщиков

Проверяет, как библиотеки MFT, Usn, Prefetch, Lnk и JumpList ведут себя на повреждённых и усечённых данных. Это инструмент разработки, он не входит в поставку XIN SKAN.

Запуск (Linux или Windows с Git Bash, нужен .NET 10 SDK и доступ к GitHub; NuGet не нужен):

```
./run.sh reports
```

- `clone-pinned.sh` клонирует исходники библиотек по коммитам из `docs/LIBRARY_REVIEW.md` в `.src/`.
- Библиотеки собираются из исходников; Serilog заменён пустой заглушкой (`SerilogShim`) — она не влияет на разбор.
- `Fuzz` подаёт каждый образец целиком, усечённым и с детерминированными повреждениями; лимит кучи 2 ГБ, тайм-аут 10 с на случай.
- `Perf` измеряет время и удерживаемую память при загрузке `$MFT` классом `Mft`.

Отчёты пишутся в указанную папку. Результаты последнего прогона — в `docs/LIBRARY_REVIEW.md`.
