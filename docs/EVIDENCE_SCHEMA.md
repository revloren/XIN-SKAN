# Схема Evidence v1

Свидетельство — одно наблюдение из одного артефакта. Оно неизменяемо: корреляция создаёт отдельные записи, ссылающиеся на свидетельства по ID, и никогда не «повышает» исходную запись. Код: `src/XINSkan.Models/Evidence.cs`.

## Поля

| Поле | Обязательно | Содержание |
| --- | --- | --- |
| `EvidenceId` | да | ULID: 26 символов, сортируется по времени создания |
| `InvestigationId` | да | ULID проверки |
| `ModuleId` | да | Анализатор, создавший запись (`file-hunter`, `history`, ...) |
| `Source` | да | Тип источника, путь к артефакту, разборщик и его версия |
| `Locator` | да | Где внутри источника: «MFT entry 1234/5», «USN 0x1F0A2B», смещение, ключ реестра |
| `EventType` | да | Existed, Created, Modified, Renamed, Moved, Deleted, Accessed, Executed, ExecutedLikely, Loaded, Downloaded, Observed |
| `Timestamp` | нет | Время события по источнику; пусто, если источник его не хранит (например, MFT не хранит время удаления) |
| `OtherTimestamps` | нет | Прочие метки того же объекта (например, все восемь меток MFT) |
| `Target` | да | Объект: путь как записан, нормализованный путь, имя, серийный номер тома, запись MFT и sequence, размер |
| `ObjectSha256` | нет | Хеш исследуемого файла — только если файл существует и прочитан целиком |
| `ArtifactSha256` | нет | Хеш исходной записи артефакта, из которой сделан вывод |
| `Confidence` | да | Informational, Low, Medium, Inconclusive (High — только у корреляции) |
| `Rationale` | да | Объяснение уровня для читателя отчёта |
| `CollectionStatus` | да | Collected, Partial, Skipped, Failed |
| `Description` | да | Что наблюдалось |
| `Limitations` | при неполном сборе | Код и текст ограничения |
| `UserSid` | нет | Профиль, которому принадлежит артефакт |
| `Attributes` | нет | Факты, специфичные для источника (старое имя при переименовании, флаги USN, ...) |
| `CollectedAtUtc` | да | Когда запись создана, UTC |

## Метка времени

`EvidenceTimestamp` хранит момент только в UTC и несёт с собой поле источника (`$SI.Created`, `Prefetch.LastRun[0]`), точность (100 нс, мс, с, 2 с, сутки), исходный часовой пояс, если источник не в UTC, и известную погрешность. `Tolerance` = точность + погрешность: корреляция сравнивает метки с этим допуском, а не как равные по точности.

## Правила, которые проверяет `Evidence.Validate()`

Запись с нарушением не принимается: модуль, который её создал, останавливается со статусом Failed, остальные продолжают работу.

1. Заполнены ID, модуль, локатор, описание и объяснение уровня.
2. **Одна запись не может иметь уровень High.** High — результат корреляции независимых источников (раздел 17 ТЗ: не присваивать High по одному признаку).
3. **Источники, фиксирующие только наличие файла, не могут утверждать запуск** (`EventType = Executed`): файловая система, MFT, USN, Корзина, `Zone.Identifier`, теневые копии. Для косвенного вывода есть `ExecutedLikely` с объяснением (раздел 7 ТЗ).
4. Статус Partial, Skipped или Failed требует хотя бы одного ограничения.
5. Объект определяется путём, именем или ссылкой на запись MFT; номер записи без sequence ссылкой не считается — записи MFT переиспользуются.
6. Все времена — UTC.

Дополнительно конвейер проверяет, что модуль пишет записи только от своего имени и только в свою проверку, и не принимает записи после завершения модуля.

## Покрытие источника

`SourceCoverage` описывает, какой период источник реально видит (самая ранняя и поздняя запись, число прочитанных элементов, статус, ограничения). Отчёт использует его, чтобы писать «до 30.10 не наблюдаемо», а не «ничего не найдено». Источник со статусом не Collected обязан указать ограничения.

## Нормализация путей

`PathNormalizer` (XINSkan.Core) приводит путь к форме для сравнения: убирает префиксы `\\?\`, `\??\`, `\\.\`, переводит `/` в `\`, схлопывает повторные разделители, лексически разрешает `.` и `..`, убирает завершающие точки и пробелы компонентов, переводит в верхний регистр. Пути вида `\Device\HarddiskVolume3` и `\VOLUME{...}` переводятся в буквы дисков только через явную `VolumeMap`; без неё они остаются отдельными строками, а не угадываются. Короткие имена 8.3, junction и переменные окружения лексически не разрешаются.
