# Minecraft Integrity

Модуль `minecraft-integrity` отвечает на вопросы: какие лаунчеры и экземпляры игры есть у пользователя, какую версию и загрузчик запускает каждый, какие параметры JVM они добавляют и **совпадают ли файлы игры с тем, что обещают её собственные файлы версий**. Код: `src/XINSkan.Analyzers.Minecraft`.

Названия чит-клиентов здесь не распознаются: это задача проверенной базы (этап 9). Модуль записывает факты (Informational) и косвенные признаки (Low). Medium ставится только за изменённый JAR клиента, у которого файл версии указывает загрузку с серверов Mojang.

## Лаунчеры

| Лаунчер | Где ищется | Что читается |
| --- | --- | --- |
| Официальный | `%APPDATA%\.minecraft` | `launcher_profiles.json` (и версия Microsoft Store): имя профиля, версия, папка игры, `javaArgs`, путь к Java, последний запуск |
| Prism Launcher, PolyMC, MultiMC | `%APPDATA%\PrismLauncher` и т. п.; переносные — в папках оператора и на уровень ниже | `instance.cfg` (INI), `mmc-pack.json` (версия, загрузчик), общий `prismlauncher.cfg` (JvmArgs для всех) |
| CurseForge | `%USERPROFILE%\curseforge\minecraft` | `Instances\*\minecraftinstance.json`; общая папка версий `Install` |
| ATLauncher | `%APPDATA%\ATLauncher` | `instances\*\instance.json` |
| Modrinth App | `%APPDATA%\ModrinthApp`, `com.modrinth.theseus` | `profiles\*\profile.json` старых версий; новые хранят настройки в `app.db` — это сказано в записи |
| TLauncher, Lunar, Badlion, Feather | их папки | только факт установки; настройки не разбираются, и это сказано в записи |

Профили других пользователей читаются только с разрешением на чужие профили.

## Сверка файлов игры

Для каждой папки игры (`versions` + `libraries`) и для метаданных Prism (`meta\*\*.json`):

- **JAR клиента** сверяется по SHA-1 с `downloads.client` файла версии (у Prism — `mainJar`).
- **Библиотеки** сверяются по `downloads.artifact` (путь и SHA-1) или, в стиле Fabric/Quilt, по имени Maven и полю `sha1`.
- **Главный класс**: известные точки входа — Minecraft, LaunchWrapper, Fabric, Quilt, Forge, NeoForge, ForgeWrapper. Другой класс — Low (так запускаются клиенты со своей точкой входа; безобидно — новый загрузчик).
- **Параметры JVM** из `arguments.jvm` файла версии и из настроек лаунчеров.

Хеш — SHA-1, потому что его публикуют Mojang и загрузчики. Файлы читаются через тот же источник, что и везде (только чтение, полное разделение, журнал аудита), с бюджетом 4 ГБ на проверку; исчерпание бюджета записывается. Пути библиотек с `..` и разделителями в именах Maven отвергаются.

| Результат | Уровень | Обоснование |
| --- | --- | --- |
| JAR клиента отличается, файл версии указывает загрузку с Mojang | **Medium** | клиент изменён после загрузки; безобидно — старые моды, встраиваемые в JAR (до 1.6), повреждение |
| JAR клиента отличается, файл версии сторонний | Low | изменённый клиент или собственная сборка лаунчера |
| Библиотека отличается | Low | подмена (authlib в «пиратских» лаунчерах, внедрение кода) или обновление и повреждение |
| Неизвестный главный класс | Low | своя точка входа клиента или новый загрузчик |
| Параметр `-javaagent`, `-agentpath`, `-agentlib`, `-Xbootclasspath`, `-noverify`, `-Djava.system.class.loader`, `-Dfabric.addMods`, `-Dfml.coreMods.load` | Low | внедрение кода — и так же профилировщики, отладчики, агенты оптимизации |

Отсутствующая библиотека (нативные файлы других ОС, ещё не скачанные) не считается проблемой; их число записывается.

**Ограничение:** сверка идёт с локальными файлами версий, их тоже можно изменить. Сверка с хешами, опубликованными Mojang, — часть проверенной базы (этап 9).

## Связь с корреляцией

Путь агента из `-javaagent` нормализуется, поэтому корреляция связывает его с JAR, найденным File Hunter, и со следами загрузки (Prefetch). Два новых правила (`docs/CORRELATION.md`):

- `AGENT_CONFIRMED` — агент прописан в настройках лаунчера **и** независимый источник показывает его загрузку → Medium;
- `MODIFIED_FILE_LOADED` — файл игры отличается от файла версии **и** загружался → Medium.

## Где проверено

| Что | Как |
| --- | --- |
| Официальный лаунчер | профили с кавычками в `javaArgs`, профиль «последний выпуск»; ванильная версия: совпадающий клиент, отличающаяся и отсутствующая библиотеки; изменённый клиент с URL Mojang → Medium; версия Fabric с наследованием и библиотеками в стиле Fabric; «клиент» со своим главным классом и `-noverify` |
| Другие лаунчеры | Prism (общие и свои JvmArgs, загрузчик из `mmc-pack.json`, клиент из `meta`), CurseForge, ATLauncher, Modrinth App, Lunar; переносной MultiMC в папке оператора; чужой профиль только с разрешением |
| Устойчивость | повреждённые JSON, библиотеки с `..` в пути, исчерпанный бюджет |
| **Настоящие файлы Mojang (CI)** | версия 1.20.1 скачивается по манифесту Mojang (SHA-1 файла версии сверяется с манифестом), затем клиент и первые 8 библиотек: всё совпадает, главный класс известен, лишних параметров JVM нет. Изменение одного байта клиента находится и получает Medium |

Форматы Prism, CurseForge, ATLauncher и Modrinth App проверены на образцах, составленных по их документации и исходному коду, а не на настоящих установках; это записано в покрытии (`MC.FORMATS`).
